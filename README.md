# ITIS-4390 Capstone Project

This repository contains the front-end files for the capstone project. Follow the steps below to run the site locally for development and testing.

## How to Run Locally

1. **Clone the repository:**
   Open your terminal and run:
   ```bash
   git clone [https://github.com/dylatrong/ITIS-4390-Capstone.git](https://github.com/dylatrong/ITIS-4390-Capstone.git)
   cd ITIS-4390-Capstone

    Open in VS Code:
    Open the cloned folder in Visual Studio Code.

    Start Live Server:

        Ensure you have the Live Server extension installed in VS Code.

        Right-click on index.html in the file explorer and select "Open with Live Server".

        The site will automatically open in your default browser and refresh whenever you save changes.
